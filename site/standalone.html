used-finds-eu

One query across the leading second-hand marketplace in every EU country — priced to your door in Portugal.

This hosted page is static, so it links rather than aggregates.

GitHub Pages serves files, not servers — so this build folds your query into each marketplace's own search URL and hands you the links, grouped by country and ranked by how much locals actually use each site. The shipping calculator and the catalogue are fully functional here. For the real thing — one merged, de-duplicated, EUR-normalised result list sorted by landed cost — run the backend and point the Live results tab at it. Two commands, in the README.

Where the item is, and roughly what it is. Routes are ranked by cost plus how much of your Saturday they consume — the cheapest option is often not the one you want. Runs entirely in your browser.

The leading second-hand platform in each of the 27 EU member states, plus the pan-European players. Rank 1 is what locals reach for first. Confidence is how sure the research is — medium and low entries are worth re-checking before you trust them.

Point this page at a running backend for real aggregated results.

The Python service does the part a static page cannot: query ~31 marketplaces in parallel, convert six currencies to EUR, drop duplicates, and sort by what the item costs delivered to Portugal. Run it locally — pip install -r backend/requirements.txt && cd backend && python -m ufeu.cli serve — then paste http://127.0.0.1:8000 below. The URL is remembered in this browser only; nothing is sent anywhere else.
