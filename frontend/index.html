used-finds-eu

One search box over Europe's second-hand marketplaces, priced to your door in Portugal.

The leading second-hand platform in each of the 27 EU member states, plus the pan-European players. Rank 1 is what locals reach for first.

Accounts are created by you, by hand — on purpose.

Every platform here requires a CAPTCHA, an SMS code or both at signup, and automating registration breaches all of their terms of service and gets accounts banned rather than created. So this tool does the honest version: you register once per site (5 minutes each, links below), and store the resulting API key or session cookie in a local encrypted vault. Most sites don't need an account to search at all — only to message a seller and buy. Start with eBay, which is a real, free, self-service API key and needs no scraping. See docs/02-accounts.md for the full playbook.
